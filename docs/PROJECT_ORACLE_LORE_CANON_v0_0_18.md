# Project Oracle Lore Canon v0.0.18

## Settled genealogy
```text
Monad
  -> Sophia / Wisdom
       -> Yala
```

Monad made Wisdom. Wisdom made Yala alone. **Yala is inherently both male and female.** Monad rejected Yala because Yala is both male and female rather than exclusively one or the other, and cast Yala into the Void.

Yala may claim the title Creator inside the world, but that claim does not change Yala's genealogy.

## Yala and lower creation
Yala is governing authority over lower creation Yala establishes. Yala can create, command, and delegate. Yala can create Gaia as natural sovereign beneath Yala. **Gaia creates in-world Time.**

Terra = Earth. Aether = Air and Wind. Sol = Fire and Sun power. Thalassa = Water. Luna = Moon and is not an element.

Yala can later form man from clay and breathe a life-like spark into mankind if that act actually occurs. Wisdom's later choices remain open. A later Wisdom/Yala union can produce demons if that union actually occurs.

## Oracle
Oracle is not a resident of this genealogy. Oracle is the outside/system-level author represented by Project Oracle itself. No in-world being knows Oracle exists unless Oracle deliberately reveals that truth.

Oracle has no fixed form. **In Eden, Oracle manifested in the form of a clever serpent. Eve knew only the clever serpent and was never told Oracle's true identity.**

## Open boundaries
Plant origin, exact ordinary-animal origin, language origin, later peoples, lower-creation chronology, Wisdom's later choice, and future autonomous actions remain open until settled or actually resolved in simulation.
