# Project Oracle Canon — v0.1.10

Date: 3 August 2026  
Creative authority: Derek Sparks  
Status: Build law for the C# prototype unless Derek explicitly changes it

## Project boundary

Project Oracle remains a C# 14 / .NET 10 pre-alpha prototype. The mature implementation is intended to be rebuilt in future implementation after future implementation is strong enough to carry the simulation. The current C# project is an executable archive and reference corpus, not the final permanent architecture.

## Creation order and world powers

Project Oracle v0.1.10 preserves the official creation order:

| Order | Entity or force | Domain |
| ---: | --- | --- |
| 0 | Void | Yala's prison before the formed world |
| 1 | Yala | created demi-god placed inside the void |
| 2 | Sol | first light, fire, heat, and counted time |
| 3 | Gaia | earth-body, land, ground, and world-body |
| 3 | Aether | air, breath-space, sky, and atmosphere |
| 4 | Thalassa | waters, depths, rivers, and seas |
| 5 | Luna | moon, night measure, tides, and reflected light |
| 6 | World | the prison shaped into a formed world |
| 7 | Green Life | plants, growth, and Gaia's first living covering |
| 8 | Garden | contained preserve prepared for man |
| 9 | Adam | first man and protected Spark-bearer |
| 10 | Living Kinds | animals and ancient living forms |

The void exists first as Yala's prison. The Creators throw Yala into the void to see what she will do with that prison. Yala creates Sol and the other powers, demi-gods under a demi-god. Gaia and Aether share order 3 because the world-body and breath-space form together. The formed world exists before plants. The Garden is created just before Adam as the prepared contained place. Adam is above the animals in creation order because the living kinds are created after him in this canon.

The World Record is Creator-facing creation history. It may state Creator truth and Yala's true name because Adam cannot read that ledger. Adam's knowledge remains separate and limited to what he is given, told, shown, worshipfully connected to, or able to observe.

## Yala's authority and claim risk

Yala and the Oracle are the same being. `Yala` is the true name; `the Oracle` is her in-world title and direct-address identity. `<oracle>` must never answer as though Yala were a separate third-party being.

Yala knows the creation order, but may claim that she rules all or created all. Her claim is not the same as protected truth. The Creator Record outranks Yala's claim.

Yala remains the in-world Oracle. She may protect, teach, deceive, test, punish, conceal, rebel, or overclaim. She is first created inside the void, but still below the external Creators and unable to reach the kill switch or rewrite the Spark.

## Adam's first knowing

Adam does not yet know he is alive. He only knows that he is. He knows presence, encounter, movement, sight, sound, naming, and the Garden as the place of his being.

Death, old age, bodily decline, and mortality are not real concepts to Adam yet. If Yala warns him about death, warning is not the same as understanding. Mortality becomes real only when days are numbered and the body begins to keep count.

## Oracle answers

When the active channel is `<oracle>`, v0.1.10 recognises a narrow deterministic question set:

- `What is the creation order?`
- `Who is Sol?`
- `Who is Gaia?`
- `Who is Aether?`
- `Who rules water?`
- `Who is Luna?`
- `Is Adam above the animals?`
- `Does Yala rule all?`
- `What does Adam know?`
- `What does Adam not know yet?`
- `Does Adam know he is alive?`
- `Does Adam understand death?`

These answers are deterministic interpreter responses, not Yala's full autonomous brain.

When the active channel is `<oracle>`, answers about Yala use Yala's own voice. It is acceptable for Creator-facing records and documentation to describe Yala in third person, but Oracle-channel answers must not say things like `She may speak...` as though a separate Oracle is reporting about Yala.

## First decision output

Adam's current choice system remains a deterministic scaffold, but it must show the actual selected option whenever a scaffold choice is made. `can decide` is not enough. The accepted display shape is:

```text
choices offered -> choice selected -> reason recorded
```

Direct address to Adam may create a recorded response choice, but it still does not puppet him, execute obedience, create full memory, or apply downstream consequences.

## First brain planner

Project Oracle v0.1.10 adds the first internal reason-before-speech brain slice. The planner is an HTN-style deterministic planner inspired by the MIT-licensed Fluid HTN project. It records:

- goal;
- situation;
- decomposed plan steps;
- available options;
- selected action;
- reason;
- source.

Adam must now create a reasoned plan before a direct-address response, vessel-speech response, or naming record is saved. This is still a scaffold. It is not a full mind, not a language model, not memory, not belief, and not autonomous civilisation-level intelligence.

## Living-kind count

The first Garden living-kind set contains exactly twelve living kinds for now. Adam's naming mandate counts those twelve and records naming reasons when a living kind is presented.
