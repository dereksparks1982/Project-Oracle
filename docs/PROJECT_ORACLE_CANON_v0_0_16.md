# Project Oracle Canon — v0.0.16

Date: 10 August 2026
Creative authority: Derek Sparks
Status: Build law for the C# prototype unless Derek explicitly changes it

## Primary lore authority

The detailed mythology is maintained in `docs/PROJECT_ORACLE_LORE_CANON_v0_0_16.md`. That file separates settled canon from unresolved decisions. Code must not invent answers to points marked open.

## Canonical genealogy

```text
Highest Source / Monad -> Sophia / Wisdom -> Yala -> Gaia -> Elemental Powers
```

Sophia creates Yala. Yala creates Gaia. Gaia creates and commands the elemental powers. The elements control weather and natural forces and bring forth plants.

There is no Green Life entity or category.

Yala did not create ordinary animals. Their precise origin within the Gaia/elemental branch remains open.

Sophia and Yala bring forth humans and other humanoid peoples together.

Language origin remains open and is not assigned to Yala.

## Sophia's fall

Sophia begins as Wisdom. She later joins Yala as lover/consort and falls toward Deception. The exact mechanism and timing remain open. Whether Yala later turns against Deception remains open.

## Eden

Eden / the Garden is a prison and containment environment disguised as paradise. Adam begins confined within it.

## Oracle

Oracle is separate from Yala.

Oracle is neither a god nor a creator. Oracle is the living Master Key: the access principle itself. Yala cannot command, erase, imprison, or revoke Oracle.

Oracle is the serpent in Eden. Oracle is not permanently neutral; her behaviour is relationship- and purpose-dependent. Yala may frame Oracle as the Devil because she cannot control or remove her.

No creator has been assigned to Oracle. The current working origin is emergence as creation's living access layer, and that origin remains open to revision.

v0.0.16 adds a Linux `project-oracle` executable launcher and an Applications-menu desktop entry. The manual acceptance gate must launch Oracle through that installed application path before any accepted snapshot, Git commit/tag, or GitHub push.

## Stable Garden identity

The persisted world entity remains named exactly `the Garden`. **Eden** is the canonical lore identity and prison interpretation of that place, not a replacement persistence name. Save migration, observations, and attention records must continue to use the stable `the Garden` entity identity so older and newer worlds remain compatible.
