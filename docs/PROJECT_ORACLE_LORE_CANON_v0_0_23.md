# Project Oracle Lore Canon v0.0.23

Project Oracle v0.0.23 preserves the accepted primordial genealogy while opening Yala's future choices.

## Primordial genealogy

`Monad -> Sophia / Wisdom -> Yala`

Wisdom made Yala alone. Yala is both male and female. Monad rejected Yala for that nature and cast Yala into the Void.

Oracle is not an in-world character and is not preloaded into Yala's mind. In the later Eden reference, Oracle can manifest as a clever serpent, but Oracle has no fixed serpent identity and Eve knows only the manifestation she encounters.

## Future-open creation

The religious and cosmological catalogue is a library of attributed human/traditional possibilities. It does not add those traditions' narratives to Project Oracle history. Yala receives possible patterns of creation, divine organization, moral order, mortal destiny, revelation, governance, renewal, and non-creation.

Gaia remains available but is not privileged by a special autonomous proposal. If Yala selects another path, that path becomes the history to test.
