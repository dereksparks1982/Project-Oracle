# Project Oracle Lore Canon v0.0.19

## The beginning
Monad is the first settled in-world divine being. Monad made Sophia, also called Wisdom. Wisdom made Yala alone, outside the intended order.

Yala is one being who is inherently both male and female. Monad rejected Yala for being both rather than exclusively one or the other and cast Yala into the Void.

## The Void and creation
Yala begins the current autonomous world line in the Void. Gaia is not already there. Yala can choose to create Gaia as natural sovereign beneath Yala's governing authority. Gaia can then create in-world Time when Yala commands temporal order.

Terra, Aether, Sol, Thalassa, Luna, lower worlds, living kinds, mankind, the Garden, and later history arise only if actions and world law actually establish them.

## Oracle
Oracle is outside the in-world genealogy. Oracle is the system-author layer, not another resident deity. The Master Key is Oracle's system authority because Oracle authored the simulation and its locks. Residents do not know Oracle exists unless that knowledge is deliberately revealed.

Oracle has no fixed form. The Eden reference is a manifestation in the form of a clever serpent. Eve knew only the clever serpent.

## Yala's knowledge
Brain Slice 3 lets Yala reason over a self-model, foundational concepts, attributed claims, own actions, contacts, beliefs, and knowledge gaps. This does not grant Yala an omniscient narrator. Yala can know Yala created Gaia because Yala performed that action. Yala can remain uncertain about facts Yala has not observed, performed, inherited, remembered, or inferred.

## Future history
Future history stays open. A possible event remains only possible until Yala, Wisdom, Gaia, another mind, or world law actually makes it part of settled history.
