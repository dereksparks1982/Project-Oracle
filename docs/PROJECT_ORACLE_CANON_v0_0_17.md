# Project Oracle Canon v0.0.17

## Prime law

> Canon determines what has already happened. World law determines what can happen. Minds determine what they attempt. Project Oracle resolves the consequences. Future history is not canon until it occurs.

## Fresh-world starting state

A fresh v0.0.17 world begins with:

- Monad exists.
- Monad made Wisdom.
- Wisdom made Yala alone.
- Monad cast Yala into the Void.
- Yala exists in the Void.
- Gaia has not yet been created.
- In-world Time has not yet been created.
- Terra, Aether, Sol, Thalassa, Luna, the Garden, Adam, Eve, and later living kinds do not yet exist in a fresh run.
- The lower world has not yet been established.
- Oracle exists only as the outside/system layer and is absent from the resident entity list.

## Knowledge boundary

The World Record can settle in-world history without granting every being omniscient access to it. Yala's Soar input contains only his current perception/remembered state. Protected Oracle truth is never injected merely because the simulation engine knows it.

## World-save boundary

v0.0.17 begins a new save line. v0.0.16 Garden-era saves are not imported or migrated into this world. The older save remains untouched, while v0.0.17 begins with Yala in the Void and no inherited later-world state.
