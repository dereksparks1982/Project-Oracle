# Project Oracle Canon v0.0.20

## System truth
Oracle is Project Oracle's outside/system-level authorial authority. Oracle is not an in-world being or direct-call target. No resident knows Oracle exists unless Oracle deliberately reveals that truth.

## Settled in-world genealogy
1. Monad is the first settled in-world divine being.
2. Monad made Sophia / Wisdom.
3. Wisdom made Yala alone, outside the intended order.
4. Yala is inherently both male and female.
5. Monad rejected Yala because Yala was both male and female rather than exclusively one or the other.
6. Monad cast Yala into the Void.

## World origin state
A fresh current-world run begins with Yala in the Void. Gaia and in-world Time are absent. Yala may create Gaia. Gaia creates in-world Time after Yala commands temporal order.

## Natural names
Terra = Earth. Aether = Air and Wind. Sol = Fire and Sun power. Thalassa = Water. Luna = Moon and is not an element.

## Eden reference
Oracle has no fixed form. In Eden, Oracle manifested in the form of a clever serpent. Eve knew only the clever serpent and was not told Oracle's identity.

## Future-open law
Possible future religious, demonic, human, Garden, and civilizational events remain possibilities until autonomous history actually establishes them. No future chronology becomes canon merely because code knows how an action could be resolved.

## Brain Slice 3 epistemic law
Yala's built-in language concepts do not constitute foreknowledge of future history. Speaker claims and proposed word definitions remain attributed claims until Yala has grounds to evaluate them. Yala's self-model may contain only self/history facts Yala can lawfully know and must not expose Oracle.

## v0.0.20 Time-display truth
The top-row clock is a presentation of in-world Time, not a second time system. Before Gaia creates Time it must state `In-world Time: Gaia has not yet created Time.` Once Gaia creates Time it presents the same world clock that persistence and simulation use.
