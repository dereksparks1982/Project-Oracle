# Project Oracle World Time Intake v0.0.25

## Settled clock law

Before Gaia creates Time, world milliseconds remain held and the visible status is exactly:

`In-world Time: Gaia has not yet created Time.`

No host time is converted into fictional in-world dates before Time exists.

If Yala creates Gaia and Gaia later creates in-world Time, the same status location switches to the live in-world clock. Existing deterministic clock, save/restore cursor, and offline progression behavior remain carried forward from accepted v0.0.24.

## v0.0.25 relationship to cognition

The Integrated Mind milestone does not change the settled clock law. Pre-contact cognitive decisions and cosmic deliberation can occur while in-world Time does not yet exist; those events retain the `before-time` temporal state rather than inventing dates.
