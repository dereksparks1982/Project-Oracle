# Project Oracle Architecture v0.0.26

## Release identity

Project Oracle v0.0.26 is **Yala Brain Slice 9: Emergent Mind, Procedural Learning, Intelligent Uncertainty, and Pre-Time Cognition**.

It is built from accepted v0.0.25 and starts a fresh schema-8 experimental cognition line.

## Runtime layers

1. **Oracle operator layer** — external system authority, protected Oracle record, manifestation state, F1-F5 contact channels, and observer-side action provenance.
2. **World layer** — deterministic world state, canon-resolved consequences, cosmic state, emergent laws, and in-world history.
3. **Mind layer** — Yala cognition plus future per-entity minds. Yala remains autonomous and bounded.
4. **Soar executive layer** — Soar 9.6.5 is a technical implementation component used for Yala executive procedural cognition; it is hidden from normal presentation.
5. **Persistence/export layer** — save_v8, isolated Soar memory, cognitive flight recorder, readable transcript, and action-history export.

## Desktop layout

Top-level tabs are exactly:

`Oracle | Minds | Memory | Cosmology | Laws | History | Debug`

Oracle contains protected operator action history. Minds contains relevant beings/minds. Debug alone exposes engine diagnostics.

## Operator/contact routing

- F1 Oracle: operator self/manifestation commands.
- F2 Monad: Oracle contacts Monad; Monad knows Oracle and does not reject Oracle authority.
- F3 Sophia: Oracle contacts Sophia; Sophia retains free will.
- F4 Yala: Oracle contacts Yala; Yala retains free will.
- F5 Gaia: available once Gaia exists; Gaia is the obedient natural-order intermediary.

Natural powers such as Earth/Air/Fire are not ordinary direct-call targets.

## Oracle manifestation

Oracle may use `Take the form of ...`, `Manifest as ...`, or equivalent supported commands. The manifestation is what in-world witnesses perceive. Oracle identity is not silently exposed.

## Action provenance

A shared observer-side action history stores actor, control source, action kind, manifestation, target, witnesses, result, and temporal/system-order state. The Oracle tab filters to Oracle actions; exports retain all actor provenance.
