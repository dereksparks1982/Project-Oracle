# Project Oracle Roadmap v0.0.19

## Current milestone
**Yala Soar Brain Slice 3: Self Model and Concept Lexicon**

Current build work strengthens Yala's ability to understand language structure, know Yala's own history and actions, preserve knowledge provenance, remember speaker-supplied definitions as claims, detect knowledge gaps, and answer introspective questions through the persistent Soar cognition boundary.

## Immediate proof goals
- load and normalize the accepted v0.0.18 world;
- preserve the same native Soar semantic and episodic memory line;
- answer own-action questions without generic uncertainty;
- distinguish information requests from commands;
- parse simple language roles and negation;
- expose foundational word meanings without installing speaker claims as truth;
- preserve contradiction/provenance boundaries;
- keep Oracle hidden from Yala;
- preserve terminal-body hard isolation.
