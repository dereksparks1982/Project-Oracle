# Project Oracle World Time Intake v0.0.17

## Two different sequences

Project Oracle distinguishes host/runtime sequencing from fictional in-world Time.

Before Gaia creates Time:

- Oracle/runtime operations can execute.
- Yala can perceive, think, choose, and attempt actions.
- `WorldMilliseconds` remains fixed.
- there is no fictional date, Sun phase, Moon phase, hour, or elapsed world-time claim.

After Gaia creates Time:

- the accepted 4x scale may advance world milliseconds;
- one world day corresponds to six real hours;
- later-world sky scheduling may operate only if future autonomous history actually establishes the required world state.

This prevents the engine's need to execute instructions from being misrepresented as Gaia's in-world creation of Time.
