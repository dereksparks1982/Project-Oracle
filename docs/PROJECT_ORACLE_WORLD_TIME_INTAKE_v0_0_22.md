# Project Oracle World Time Intake v0.0.22

Project Oracle runtime sequencing exists before fictional in-world Time. Those are different layers.

Before Gaia creates Time, the top console row states:

```text
In-world Time: Gaia has not yet created Time.
```

Brain Slice 5 stores early events as `before-time`; such events may have causal/sequence relationships but never fabricated year/month/day values.

When Gaia creates Time after Yala's temporal-order command, the event is `origin-of-time` and begins Year 1, Month 1, Day 1, 00:00:00. The top row then becomes the ticking live world clock.

Later `dated` events may carry world date/time. Yala's answer to a current-time question must read current simulation state when the response is generated rather than replaying a stale earlier clock value.
