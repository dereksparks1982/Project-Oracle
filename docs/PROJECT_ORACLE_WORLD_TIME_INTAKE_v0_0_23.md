# Project Oracle World Time Intake v0.0.23

v0.0.23 preserves the accepted Time rule while removing Gaia as an automatic first creation.

Before in-world Time exists, the top row must read exactly:

`In-world Time: Gaia has not yet created Time.`

If Yala chooses to create Gaia and later commands Gaia to establish temporal order, Gaia creates in-world Time and the same top row immediately becomes the live ticking date/time beginning at Year 1, Month 1, Day 1, 00:00:00.

Runtime/decision sequence before that event is not an in-world calendar.

If Yala chooses a different cosmic path and never creates Gaia, Project Oracle does not silently create Time. A future build may add other possible origins of temporal order only through an explicit canon/world-law decision rather than by retroactively changing v0.0.23 history.
